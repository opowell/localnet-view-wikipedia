# Wikipedia view for Localnet

How a page looks in Read in Localnet, a browser extension that is a personal search engine, after Wikipedia: the title
and each section's heading in a serif over a hairline rule, the text in a sans with blue links, the facts of an
infobox in a grey box, a table's cells ruled with its headings shaded, each picture framed over its caption, and the
references numbered in a smaller face; light, or in Wikipedia's night colours where Localnet is dark. Listed by the
view source Localnet starts with, [localnet-views](https://github.com/opowell/localnet-views), whose README says how a
view is written.

- `source.json`: the view, and its files.
- `content.html`, `content.css`: the content view, Read's Look: its head over the page (the title, and the site it is
  from), and the page restyled.
